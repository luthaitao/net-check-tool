# 网络检查工具 · NetCheckTool

一个**零依赖**的本地网络诊断工具，包含两大功能：

1. **端口连通性检测** —— 输入 IP 或机器名 + 端口，判断端口是否开放
2. **类 Postman API 调试台** —— 构造/发送 HTTP 请求，查看响应，编写断言

支持桌面程序（Electron 独立窗口）与浏览器版两种形态，**运行时零第三方依赖**。

## 它能做什么

**端口连通性检测**

- 端口支持 `80`、`80,443`、`8000-8100` 混写，解析后自动去重排序
- 区分「连接被拒绝」与「连接超时」——前者是端口没开，后者通常意味着防火墙静默丢包，两者排障含义完全不同
- 被动抓取 Banner 识别 SSH / MySQL / HTTP 等真实服务类型（只读不发，不触发协议状态机）
- 并发扫描、结果筛选、CSV 导出（带 BOM，Excel 打开中文不乱码）

**类 Postman 的 API 调试台**

- 7 种方法、查询参数表、请求头表
- 四种请求体：`raw`（JSON/XML/Text/HTML，可一键格式化）、`x-www-form-urlencoded`、`multipart/form-data`（支持真实文件上传）、无
- 鉴权：None / Basic / Bearer / API Key（Header 或 Query）
- **五段耗时拆解**：DNS / TCP / TLS / 服务端处理 / 下载，定位慢在哪一环
- 完整重定向链记录（关闭自动跟随后可查看 302 跳去哪了）
- JSON 自动格式化高亮、HTML 沙箱预览、二进制响应不乱码可下载
- 断言引擎：11 种来源 × 24 种算子，JSON 路径支持嵌套与数组下标
- 环境变量（`{{变量名}}`）、请求集合、历史记录、cURL 一键导出

**输入说明悬浮提示** —— 每个填写位都带示例说明，鼠标悬停即可查看。

## 快速开始

> 仓库内**不含**预编译的 exe（单个 70MB+，不适合入库）。
> 克隆后按下面「源码运行」启动，或按文末「构建说明」自行打包。

### 源码运行（需要 Node.js 18+，无需 npm install）

```bash
node server.js                      # 默认端口 7801，绑定 127.0.0.1
node server.js --port 9000 --open   # 换端口并自动开浏览器
```

浏览器访问 `http://127.0.0.1:7801/`。

> ⚠️ **不能直接双击 `index.html`** —— 浏览器安全策略禁止网页发起原始 TCP 连接，
> 端口检测必须由本地进程代发请求。页面右上角有徽标显示后端连接状态。

### 构建单文件 exe

```bash
# 浏览器版（Node SEA，目标机器无需装 Node）
npm install postject --no-save
node build/build-exe.js             # → 网络检查工具.exe（浏览器打开）

# 桌面版（Electron 独立窗口，不占浏览器）
npm install electron electron-builder --save-dev
npx electron-builder --win portable # → dist-desktop/网络检查工具-*.exe
```

## 安全设计

本工具具备**端口扫描**与**任意 HTTP 请求**能力，因此：

- 默认只监听 `127.0.0.1`，仅本机可访问；
- 静态文件服务做了路径穿越防护（`..%2f..%2fserver.js` 会被拒绝）；
- JSON 请求体有 32MB 上限，响应体上限 20MB，防止内存被撑爆；
- **跨域重定向自动剥离 `Authorization`**，避免凭据泄漏到新主机。

> ⚠️ 请仅在自己有权访问的网络环境中使用。扫描他人系统可能违反法律或公司规定。

## 常见问题

**Q：为什么不能直接双击 `index.html`？**
浏览器不允许网页发起原始 TCP 连接，必须通过本地服务访问。

**Q：提示「超时」是不是就代表端口没开？**
不是。超时说明报文被静默丢弃，通常是防火墙 DROP 策略；端口确实没开会表现为「连接被拒绝」。

**Q：端口 0–1023 检测不了？**
在 Windows 上通常不受限；若报「权限不足」，Linux/macOS 需以管理员运行。

**Q：数据存在哪里？**
环境变量、请求集合、历史记录存在浏览器 `localStorage`（前缀 `netcheck.`），不上传任何服务器。
历史记录只存请求配置与状态码摘要，不存响应体。

## 为什么需要本地服务端？

浏览器出于安全限制**不允许网页发起原始 TCP 连接**，因此「检测端口是否开放」和「绕过跨域限制」这两件事纯前端都做不到，必须有一个本地进程代发请求。这也是为什么不能直接双击 `index.html` 使用——请通过上面的方式启动。

## 功能一：端口连通性检测

### 用法

1. 输入 **IP 地址或机器名**（如 `192.168.1.1`、`server01.corp.com`、`localhost`）
2. 输入 **端口**，支持以下写法混用：

| 写法 | 含义 |
|---|---|
| `80` | 单个端口 |
| `80,443,8080` | 多个端口 |
| `8000-8100` | 端口区间（含首尾） |
| `1-100,443,8080` | 混合，解析后自动去重并按数字排序 |
| `80，443、22` | 中文逗号 / 顿号也支持 |

3. 点击 **开始检测**

### 输出内容

| 字段 | 说明 |
|---|---|
| 状态 | 开放 / 关闭 / 超时 |
| 服务 | 根据端口号 + Banner 特征推断（如 `SSH`、`MySQL`、`HTTP`） |
| 响应时间 | TCP 握手往返耗时（毫秒） |
| 说明 | 失败时给出中文原因，例如「连接被拒绝（端口未监听 / 服务未启动）」 |
| Banner | 开启抓取时显示服务握手首包（如 SSH 的 `SSH-2.0-…`） |

### 状态判定依据

| 现象 | 判定 | 含义 |
|---|---|---|
| 连接成功 | **开放** | TCP 三次握手完成 |
| `ECONNREFUSED` | 关闭 | 主机可达，但该端口没有服务在监听 |
| `ETIMEDOUT` | 超时 | 报文被防火墙静默丢弃（**不是**服务关闭的证据） |
| `EHOSTUNREACH` / `ENETUNREACH` | 关闭 | 无路由 / 主机离线 |
| `EAI_NONAME` | 关闭 | 主机名解析失败 |

> **关键区分**：「关闭」和「超时」含义完全不同。超时通常意味着中间有防火墙 DROP 策略，而不是端口没开——这是排障时最容易误判的地方。

### 关于 Banner 抓取

采用**被动**方式：连上后只读取、不主动发送探测包，避免在生产设备上触发协议状态机（有副作用）。端口数 ≤ 50 时默认开启，扫描大量端口时自动关闭以缩短耗时。

### CSV 导出

结果可导出为 CSV（含 BOM，Excel 直接打开中文不乱码），字段：端口、状态、服务、响应时间、错误码、说明、Banner。

## 功能二：API 调试台

### 能力清单

**请求构造**
- 方法：GET / POST / PUT / PATCH / DELETE / HEAD / OPTIONS
- 查询参数表（可批量启停）
- 请求头表（不区分大小写，自动补 `Accept` / `Accept-Encoding` / `User-Agent`）
- 请求体四种模式：
  - `raw`：JSON / XML / Text / HTML / JavaScript（可一键格式化）
  - `x-www-form-urlencoded`
  - `multipart/form-data`（**支持真实文件上传**，字段类型选「文件」后可选本地文件）
  - 无请求体
- 鉴权：None / Basic / Bearer / API Key（Header 或 Query）

**响应查看**
- 状态码 + 状态文案 + 耗时 + 大小 + HTTP 版本 + 服务端地址
- JSON 自动格式化并语法高亮；XML 高亮
- 响应头全表（可搜索）、Cookie 解析（含属性）
- 响应体内搜索高亮
- HTML 响应在「预览」页签内沙箱渲染
- 二进制响应不乱码，可直接下载
- **耗时分析**：DNS / TCP / TLS / 服务端处理 / 下载 五段拆解 + 占比条

**跳转链路**
- 完整重定向链（`302 → 301 → 200` 每跳都记录来源与目标）
- 可关闭自动跟随，用于定位 302 问题
- **跨域跳转自动剥离 `Authorization`**，避免凭据泄漏到新主机

**调试辅助**
- 一键生成 **cURL** 命令（变量已展开，可直接粘贴到终端执行）
- 环境变量：URL / Header / Body 中用 `{{变量名}}` 引用
- 请求集合：保存、命名、删除，支持导出/导入 JSON
- 历史记录（最近 40 条，只存配置与结果摘要，不存响应体）
- 忽略 TLS 证书错误（自签名 / 过期证书调试）
- `Ctrl + Enter` 快速发送

### 断言（测试脚本）

给请求添加断言，发送后自动判定。**断言在服务端对完整响应求值**，不受前端显示长度限制，也不受响应体截断影响。

支持来源：状态码、状态码分组（2xx/3xx/4xx/5xx）、响应时间、响应头、Cookie、响应大小、响应头数量、Cookie 数量、JSON 字段、响应文本、JSON 键列表。

支持算子（24 种）：

```
等于 / 不等于 / 包含 / 不包含 / 匹配正则 / 不匹配正则
大于 / 大于等于 / 小于 / 小于等于
长度等于 / 长度大于
为空 / 不为空 / 为 null / 不为 null
是数字 / 是字符串 / 是布尔 / 是数组 / 是对象
为 true / 为 false / 路径存在 / 是 base64
```

**JSON 路径**支持嵌套与数组下标：

```
$.data.id          → 取字段
$.data.tags[1]     → 取数组第 2 个元素
data.name          → 省略 $ 也可以
```

示例模板（界面上有「快速插入模板」下拉）：

| 模板 | 规则 |
|---|---|
| 状态码 = 200 | `status equals 200` |
| 状态码为 2xx | `statusGroup 2xx isTrue` |
| 响应时间 < 500ms | `time total lt 500` |
| JSON 中 code = 0 | `bodyJson $.code equals 0` |
| JSON 中 msg 非空 | `bodyJson $.msg isNotEmpty` |
